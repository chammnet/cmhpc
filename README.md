# cmhpc

A personal collection of scripts, modules, and tools I've built for my own use - systems administration, PowerShell automation, and audio/media production. Built to solve specific problems I had; no guarantee anything here works outside my own environment.

## Layout

- `PowerShell/Modules/` - custom PowerShell modules I've written
- `PowerShell/Scripts/` - standalone scripts
- `PowerShell/Profile/` - my PowerShell profile
